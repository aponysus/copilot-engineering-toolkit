# Project context

Read the repository's root `AGENTS.md` and applicable nested instructions before
working in a subsystem. If they are missing or incomplete, inspect repository
evidence and state material unknowns; do not invent project facts.

Project instructions and maintained contracts establish local conventions and
invariants. Use available skills when relevant to the task. A textual reference
does not prove that a file or skill was loaded. Preserve project-owned guidance
and report conflicts instead of silently replacing it with shared preferences.
